defesacivil-db:latest

Imagem customizada baseada em PostgreSQL 15 + PostGIS 3.3 com script automático de inicialização das extensões espaciais (`postgis` e `postgis_topology`) e healthcheck nativo. 

FROM postgis/postgis:15-3.3

LABEL maintainer="Defesa em Foco"
LABEL description="PostgreSQL 15 + PostGIS"

COPY init-postgis.sql /docker-entrypoint-initdb.d/01-init-postgis.sql

EXPOSE 5432

HEALTHCHECK --interval=10s --timeout=5s --retries=5 \
  CMD pg_isready -U ${POSTGRES_USER:-defesa_user} \
      -d ${POSTGRES_DB:-defesa_civil} || exit 1

2. API Spring Boot 3

defesa-backend/Dockerfile
defesacivil-backend:latest

Build multi-stage: estágio 1 compila o projeto Maven com JDK 17 Alpine; estágio 2 gera imagem enxuta apenas com JRE 17, curl para healthcheck no Actuator e usuário não-root. 

# Stage 1: Build Maven
FROM maven:3.9.6-eclipse-temurin-17-alpine AS build
WORKDIR /app
COPY pom.xml .
RUN mvn dependency:go-offline -B
COPY src ./src
RUN mvn clean package -DskipTests -B

# Stage 2: Runtime JRE 17
FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
RUN apk add --no-cache curl
COPY --from=build /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]

3. Web App Flutter

Dockerfile.flutter
defesacivil-frontend:latest

Build multi-stage: compila o código Dart/Flutter para Web (`--release`) injetando variáveis via `--dart-define` e empacota os estáticos em um servidor Nginx Alpine leve. 

# Stage 1: Build Flutter Web
FROM ghcr.io/cirruslabs/flutter:stable AS build
WORKDIR /app
COPY pubspec.* ./
RUN flutter pub get
COPY . .
RUN flutter build web --release \
    --no-tree-shake-icons

# Stage 2: Servidor Nginx Alpine
FROM nginx:alpine
COPY --from=build /app/build/web /usr/share/nginx/html
COPY nginx/flutter.conf /etc/nginx/conf.d/default.conf
EXPOSE 80

services:
  db:
    image: defesacivil-db:latest
    networks: [defesa-net]
    deploy:
      replicas: 1
      placement:
        constraints: [node.role == manager]

  backend:
    image: defesacivil-backend:latest
    networks: [defesa-net]
    deploy:
      mode: replicated
      replicas: 3
      update_config:
        parallelism: 1
        delay: 10s
        order: start-first
      restart_policy:
        condition: on-failure

  frontend:
    image: defesacivil-frontend:latest
    networks: [defesa-net]
    deploy:
      mode: replicated
      replicas: 2

  nginx-lb:
    image: nginx:alpine
    ports:
      - target: 80
        published: 8000
        mode: host
      - target: 8080
        published: 8080
        mode: host
    networks: [defesa-net]
